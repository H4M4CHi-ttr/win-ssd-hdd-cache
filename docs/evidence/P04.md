## Pre-implementation counterexample review

Independent preflight required actual completion holds even when logging is
disabled/full, no post-forward extension access after inline completion, separate
slot-retirement and remove-rundown events, final-fallible SafeAttach, synchronized
single-target claim, unavailable CDO before publication, and late CDO cleanup
without stale target pointers. The draft incorporated those obligations.

Full contract review then requested deterministic archive/history/terminal/reason
predicates, first-submit classification under duplicate metadata and an exact
major/minor-to-v2 operation mapping. It also identified a mismatch between the
stop-on-transport-failure live algorithm and a lost-first-drain schedule; the
latter must be explicitly adversarial offline evidence, not an executable live
success claim. No tests or source were written before resolving these requests.

Root then found a separate authorization TOCTOU in the draft: validating owner,
releasing publication, and only later mutating an Unarmed recorder allowed
CLEANUP to clear ownership before a delayed BEGIN. The bounded command now holds
publication through nested recorder mutation/encoding, with DPC-level inner-lock
acquire/release and no wait/allocation/forward/completion while locked. CREATE
and CLEANUP use the same identity serialization; CLOSE cannot clear a later
owner. Fixed schedules cover both CLEANUP/BEGIN orders and late old CLOSE.
Unarmed cleanup has no begun session to lose and does not poison a later BEGIN.
