# P01 — bounded offline capture completeness audit

Date: 2026-11-03 JST. Task [P01 #79](https://github.com/H4M4CHi-ttr/win-ssd-hdd-cache/issues/79), normative [capture envelope v1](../contracts/capture-envelope-v1.md), fixed [implementation plan](../superpowers/plans/2026-11-03-p01-capture-audit.md). This tool audits a **supplied, post-collection projection**. It is not a kernel producer/collector, Windows capture test, authentic source attestation, permission decision or mutation-coverage certificate. An exit0 verdict cannot close D01 or any driver gate.

## Implemented boundary

- Pure Rust `cache_types::capture::audit_capture(&str)` and a separately named `cache-capture-audit` binary. Existing strict object/required-null adapters and ordinary-file reader are reused; no new dependency or change to existing CLI commands, device, network, unsafe or privileged operation.
- At most1,048,576 UTF-8 bytes and4,096 records. Root/records must be objects; all keys, including nullable ones, are required. Duplicate/escaped duplicate, unknown fields, JSON number ambiguity, overflow and malformed provenance shapes are rejected without echoing source text.
- First submit fixes request identity/target; first completion consumes completion identity even if orphaned or mismatched. Duplicate submissions/completions cannot repair, rebind, reopen or double-count a request. Request IDs are session-global, not target-local.
- No sorting or synthesized records. Attempt ordinals, dropped counters, boundary-inflight counts, finalize state, unknown range/operation and provenance presence produce a deduplicated14-code fixed-order reason set. Checked overflow never becomes a successful wraparound.
- Only privately constructed `internally_complete` or `incomplete` reports. All four producer/authorization/coverage/kernel-runtime verification flags remain false. Status/information are validated as observations, not silently rewritten to success or inferred physical transfer.

The byte-range unit is target-relative logical bytes at the declared observation point. Unknown conversion/range remains null. This checker cannot validate a collector's truthfulness, units, anonymity, target mapping or synchronization. A plausible Windows version/source hash does not authenticate anything. The original capture/inventory remains necessary and private.
